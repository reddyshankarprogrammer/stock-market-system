# ai-command-history

A record of what was asked of the AI assistant (Claude Code) on this repository and what was actually done, in order. Every entry points to the files in [research-doc/](../research-doc/README.md), which hold the plans, decisions and prompts the work follows.

## How to keep this folder

- One file per working day: `YYYY-MM-DD-session-log.md`.
- One entry per request: the request, the steps executed, the result, and links to the `research-doc` files it relates to.
- Record failures and denied actions as they happened; do not tidy them away.
- Always link to `research-doc` rather than copying its content. If a plan changes, update the `research-doc` file and note the change here.
